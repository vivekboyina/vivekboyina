# Setup — Vivek Boyina GitHub Profile

This version is intentionally built around the same **type of GitHub-native animations** you liked in JAY4IGNITE:

- animated typing SVG
- real 3D contribution calendar generated by GitHub Actions
- real contribution snake generated from your GitHub contribution graph
- live GitHub stats
- live top-language stats
- live streak stats

## 1. Create the profile repository

Create a **public** repository named exactly:

`vivekboyina`

## 2. Copy the files

Copy:

```text
README.md
.github/workflows/profile-3d.yml
.github/workflows/snake.yml
profile-3d-contrib/
```

to the root of `vivekboyina/vivekboyina`.

## 3. Enable Actions

Go to:

Repository → Actions

Run these manually once:

- Generate 3D Contribution Calendar
- Generate Contribution Snake

The workflows then update the generated SVG files automatically.

## 4. LinkedIn

The LinkedIn button currently uses:

https://www.linkedin.com/

Replace that URL with your real LinkedIn profile.

## 5. Project links

The project table intentionally does not invent repository URLs. Add the real links when the repositories are public.

## Important

The 3D calendar and snake are not videos. They are generated SVG/image assets based on your GitHub contribution data.

The 3D calendar workflow is based on `yoshi389111/github-profile-3d-contrib`.
The snake workflow is based on `Platane/snk`.
